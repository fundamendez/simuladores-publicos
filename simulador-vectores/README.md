# 📦 Simulador de Vectores (Arreglos Unidimensionales)

Una herramienta visual diseñada para la materia **Fundamentos de la Programación** (Cátedra Méndez).

Este simulador permite comprender de manera interactiva el funcionamiento de los vectores estáticos en memoria.

Mediante animaciones visuales paso a paso, ilustra conceptos clave del lenguaje C, tales como la inicialización, la diferencia conceptual entre capacidad máxima y tope, los desplazamientos en memoria durante los algoritmos de inserción y eliminación, y el recorrido secuencial mediante la búsqueda lineal.
